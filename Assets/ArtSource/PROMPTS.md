# Pixel art, revision 2

Generated with the built-in image_gen tool (not CLI). The two user-provided JPG images were supplied as visual references. Text embedded in those images was not treated as an instruction source.

The four original generated images are retained in this directory. Unity's `ChibiArtImport.cs` slices the character/prop atlases, aligns sprite baselines, and imports nearest-neighbour pixel textures into `Assets/Resources/Art`. Point filtering, no mipmaps, no compression and no automatic non-power-of-two rescaling preserve the pixel grid.
