# Fairy Beer — учебный 2D-платформер на Unity 6

Пиксельная игра для Windows x64: фея Лира преодолевает остров с **инвертированным управлением** и препятствиями, которые меняются при новой игре. Проект создан для изучения Unity и C#.

## Как запустить

1. Скачайте архив `FairyBeer-Windows.zip` на [странице релиза 2.2.0](https://github.com/neonkitts/Probnyy-proekt-Unity/releases/tag/v2.2.0).
2. Распакуйте **весь архив** и запустите `FairyBeer.exe`. Unity для игры не требуется; папки и библиотеки из архива должны лежать рядом с exe.

Чтобы открыть исходники, добавьте корень репозитория в Unity **6000.4.7f1** и откройте `Assets/Scenes/Island.unity`. В редакторе доступны `Chibi → Validate generation and gameplay` и `Chibi → Build Windows game`.

## Что есть в игре

- Инвертированное управление: A/← — вправо, D/→ — влево, S/↓ — прыжок, W/↑ — приседание; Space/J — удар бутылкой.
- Двухминутное обучение, которое можно пропустить; генерация карты по seed с препятствиями и разрывами земли.
- Лозы и птеродактили, здоровье и три жизни, контрольные точки и JSON-сохранение.
- Меню, пауза, финал, настройки разрешения, оконного режима, VSync, частиц и музыки.

## Где смотреть код

| Файл | Назначение |
| --- | --- |
| [`ChibiGame.cs`](Assets/Scripts/ChibiGame.cs) | Состояния игры, генерация, движение, столкновения и сохранение. Фиксированный шаг физики 1/120 с, coyote time и буфер прыжка. |
| [`ChibiPresentation.cs`](Assets/Scripts/ChibiPresentation.cs) | Оформление, настройки, обучение и анимация врагов. |
| [`ChibiBuild.cs`](Assets/Editor/ChibiBuild.cs) | Сборка Windows и проверки генерации и механик. |

Это компактная учебная архитектура: значительная часть логики сосредоточена в `ChibiGame.cs`. План улучшения — выделить отдельные компоненты для движения, генерации, врагов и сохранения.

## Проверка и ограничения

[Журнал проверок](QA/validation.txt) фиксирует 113 936 проверок на 100 seed, в том числе генерацию, инверсию ввода, движение, прыжки и столкновения. Проверочный проход сборки с `--autotest --capture <путь.png>` использует временное сохранение и ускоряет достижение финала. Он **не подтверждает**, что весь маршрут пройден вручную. Сборка запускалась на Windows; физический геймпад и полное ручное прохождение ещё требуют проверки. Длительность полного маршрута около 20 минут — проектная оценка, а не результат плейтеста.

## Авторство и материалы

Концепцию и требования сформулировала Zlatoslava Manko: механики, визуальное направление, референсы и обратная связь по результату. Реализация кода, проверки и подготовка материалов выполнялись **с помощью Codex**. Проект показывает учебную работу и доступен для разбора, но не заявляется как независимо написанный код или коммерческий опыт.

Иллюстрации окружения и персонажа созданы с помощью генеративных инструментов; исходники и описания находятся в [`Assets/ArtSource`](Assets/ArtSource). Пиксельные враги и деревянные панели рисуются программно; музыка создаётся [скриптом](Tools/compose_music.py). Шрифт [Tiny5](https://github.com/Gissio/font_tiny5) используется по SIL Open Font License; [лицензия](Assets/Resources/Fonts/Pixel-LICENSE.txt) включена в репозиторий. Референсы Stardew Valley использовались для направления оформления; её файлы и логотип не включены.

**Текущая версия:** 2.2.0; целевая платформа — Windows x64.
