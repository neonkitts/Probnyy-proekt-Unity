# Chibi / Fairy Beer — версия 2.1.1

2D-платформер для Windows. Проект Unity 6000.4.7f1, без сторонних пакетов.

## Исправление управления 2.1.1

В готовой FairyBeer.exe устранено взаимное обнуление перевёрнутого клавиатурного ввода и стандартной оси Unity. Клавиатура и геймпад обрабатываются отдельно. A/← ведёт вправо, D/→ — влево, S/↓ — прыжок, W/↑ — присед, Пробел/J — бутылка. Нажатые одновременно противоположные клавиши останавливают фею. Для геймпада добавлены отдельные оси и мёртвая зона стика.

При переключении в другое окно игра ставится на паузу. Вернуться можно кнопкой продолжения или Esc. Автотесты используют отдельное временное сохранение и не заменяют прогресс игрока.

## Запуск

Откройте `Builds/Windows/FairyBeer.exe`. Папка `FairyBeer_Data`, UnityPlayer.dll и остальные файлы сборки должны оставаться рядом с exe.

Для редактирования добавьте эту папку в Unity Hub и откройте `Assets/Scenes/Island.unity`. Нажмите Play. Игра создаётся компонентом `ChibiGame` при запуске сцены. Сборка: меню **Chibi → Build Windows game**. Проверки: **Chibi → Validate generation and gameplay**.

Проект физически расположен на D:\CodexProjects\Chibi: при создании на C: не было свободного места. Папка результатов Codex содержит ссылку на него.

## Управление

| Клавиша | Действие |
|---|---|
| A / стрелка влево | Идти вправо |
| D / стрелка вправо | Идти влево |
| S / стрелка вниз | Прыгать |
| W / стрелка вверх, удерживать | Пригнуться |
| Пробел / J | Ударить бутылкой |
| Esc | Пауза / продолжить |
| M | Включить / выключить звук |
| F11 | Полноэкранный / оконный режим |

«Асинхронные» направления из описания реализованы как противоположные. Удар и меню не инвертированы. Прыжок поддерживает небольшой запас времени после схода с края и буфер раннего нажатия.

## Правила

- 3 жизни, в каждой 100 здоровья. Счётчики находятся справа вверху.
- После первых двух потерь жизни фея возвращается к последнему фонарю с полным здоровьем; серая дымка усиливается и остаётся до новой игры.
- Сова-птеродактиль появляется на одну секунду после четырёх секунд неподвижности. Клюёт на середине пролёта: 80 урона. Если вовремя отойти, можно избежать удара.
- На маршруте 8 голубых цветущих лоз. Контакт наносит 30 урона. Их можно обойти прыжком/пригибанием или срезать бутылкой.
- Блоки твёрдые. Нижние нужно перепрыгнуть, под верхними — пригнуться. Падение с острова наносит 50 урона и возвращает к фонарю.
- Краткая неуязвимость после урона предотвращает мгновенную потерю всех жизней.
- Каждые 10 искорок дают 20 здоровья. Фонари каждые 320 единиц пути также восстанавливают 20 здоровья и сохраняют прогресс.
- При потере жизни геометрия остаётся прежней. После проигрыша и любого полного перезапуска создаётся новый seed и новая карта.
- В конце находится сакура с дуплом. При входе фея исчезает, затем появляется переход загрузки и финальная иллюстрация со статистикой.
- Полный путь: 4800 единиц, рассчитан примерно на 20 минут с препятствиями. Это целевая оценка, не результат пользовательского плейтеста. Короткий маршрут: 1100 единиц, около 5 минут.

## Сохранения

`Chibi-v2.save.json` создаётся рядом с exe (в редакторе — в корне проекта). «Продолжить» возвращает к последнему фонарю. Сохраняются seed, жизни, здоровье, искорки, срезанные лозы и время. После проигрыша/победы сохранение удаляется. Файл можно удалить вручную для сброса.

## Состав

- `Assets/Scripts/ChibiGame.cs`: генератор карты, фиксированный шаг движения 120 Гц, столкновения, состояние игры, интерфейс, сохранения и синтез звука.
- `Assets/Editor/ChibiBuild.cs`: настройка сцены, Windows-сборка и автоматические проверки.
- `Assets/Resources/Art`: детальные пиксельные спрайты по предоставленным референсам. Персонаж, лес, земля, блоки, лоза, птеродактиль и сакура заменены в версии 2.
- `Assets/ArtSource`: исходные атласы, созданные встроенным image_gen, и полный набор промптов в `PROMPTS.md`.
- `Assets/Editor/ChibiArtImport.cs`: нарезка атласов, выравнивание кадров и импорт с Point-фильтрацией, без сжатия и изменения пиксельной сетки. Повторный импорт: **Chibi → Import pixel artwork**.
- `Assets/Resources/Fonts`: Georgia Bold и Segoe UI из установленной Windows, с поддержкой кириллицы.
- `Assets/Resources/Audio/MoonlitReel.wav`: новая оригинальная стереотема на 91 секунду, 6/8, 64 такта, четыре части; мелодия, бас, арпеджио и перкуссия. Источник композиции — `Tools/compose_music.py` (Python + NumPy). Эффекты действий синтезируются внутри игры.
- `QA`: результаты автоматических проверок и скриншоты сборки.

Персонаж имеет позы ходьбы, прыжка, пригибания и удара; крылья и пузырьки поддерживают образ феи. Пузырьки со звуком появляются каждые три секунды. Окружение включает параллакс голубых ив, луну, светлячков, розовую землю и персиковые/мятные препятствия. Главное меню содержит только название и кнопки начала, продолжения, настроек и выхода. Длина маршрута и громкость находятся в настройках; подсказки управления — внутри уровня. В версии 2 шаг между группами препятствий уменьшен с 16 до 8,5 единицы, добавлены шесть типов связок, включая ступени и сочетания навеса с нижним блоком. Восемь лоз сохранены по исходному заданию.
